# Product direction

## Current direction

A canvas for experimenting with images. Users upload images, explore effects and colors, and export the canvas as a PNG for use in their own designs. Card previews are optional context; preview exports are not a product priority. Mottle is a temporary name.

## Initial direction

This file records the user's request separately from the assignment reference.

- Create a halftone icon generator and pattern generator for UI cards and similar uses.
- Select an image and convert it into a halftone or dither illustration.
- Explore controls using DialKit.
- Keep the first version simple and tasteful; iterate later.
- Think image-to-ASCII art, with shaders, dithers, and gradients.

Initial implementation: browser-only React + Canvas, live DialKit controls, generated sample artwork, image uploads, procedural patterns, and PNG export. A GPU shader renderer can be explored later if needed.
